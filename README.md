# Codex Usage Dock

Локальная адаптация [AI Usage Dock](https://github.com/GChavez0210/AIUsageDock), лицензия MIT.

## Плашки

1. В Command Palette выполните `Add Codex band`. Повторяйте для любого числа аккаунтов.
2. В Settings → Dock → Bands закрепите созданную `Codex N usage`.
3. Нажмите на плашку и выберите `Sign in with ChatGPT`.
4. В браузере выберите нужный аккаунт. После входа закройте окно входа клавишей Enter.
5. Плашка обновится. На странице аккаунта откройте `Usage and reset times` для подробностей.

Новая плашка по умолчанию не авторизована. У каждого номера отдельная авторизация и кэш. `Rename band` на странице плашки задаёт своё имя (1–60 символов), сохраняя профиль и привязку к Dock.
Номера не используются повторно после удаления: новая плашка не подхватит старый вход.
Команда `Unband <имя>` или `Unband and sign out` на странице плашки выполняет выход через Codex CLI и удаляет профиль с сохранённой авторизацией. Обычный Unpin в Dock по-прежнему лишь открепляет плашку.
Список плашек хранится между запусками в `%USERPROFILE%\.codex-usage-dock\accounts.json`.
При обновлении с версии для двух аккаунтов существующие профили и номера сохраняются.

Плашки показывают остаток лимитов за 5 часов и неделю, а страницы деталей — время сброса,
обратный отсчёт, email аккаунта и тариф. Проверьте email, чтобы не войти в один аккаунт дважды.
Обновление раз в минуту, последовательно: число одновременно запущенных CLI ограничено одним
для фонового обновления. Есть `Refresh AI usage` и обновление отдельного аккаунта.
Рекомендуется размещать плашки после Performance Monitor (особенность исходного проекта).
Закрепление новой плашки в Dock выполняется в настройках Command Palette.
Только иконка Codex в плашке становится жёлтой при остатке 20% и ниже, красной при 5% и ниже.
Цвет определяется по наименьшему остатку среди доступных окон лимита (включая неделю).

## Авторизация

На странице `Usage, history and reset times` под компактным блоком текущих лимитов
показывается график использованного лимита Codex или Claude за последние 24 часа: зелёный — 5 часов,
синий — неделя. Замеры сохраняются раз в минуту при успешном обновлении, история хранится
14 дней в `usage-history.json` внутри профиля плашки. Повторные чтения кэша и неудачные
обновления не добавляют точки. Пропуски более 5 минут и сбросы лимитов разрывают линии.
После смены аккаунта история начинается заново; `Unband` удаляет её вместе с профилем.
Прошлый расход до установки этой версии восстановить нельзя.

Профили находятся в `%USERPROFILE%\.codex-usage-dock\profiles\account-N`.
CODEX_HOME задаётся только дочернему процессу. Вход в Codex desktop остаётся отдельным.
Codex CLI отвечает за вход, хранение и обновление токенов. Расширение не читает токены.
Файлы auth.json содержат секреты: не публикуйте и не передавайте их.
Лимиты запрашиваются через account/read и account/rateLimits/read без задач модели.
Для смены аккаунта нажмите `Sign in to a different account` на его странице.

## Claude

`Add Claude band` создаёт плашку без авторизации. Закрепите её в Dock, нажмите на неё
и выберите `Sign in to Claude`. Вход выполняется через `claude auth login --claudeai`.
Можно создавать любое число плашек, переименовывать их и удалять через `Unband`:
эта команда выполняет `claude auth logout` и удаляет профиль плашки.

Профиль: `%USERPROFILE%\.codex-usage-dock\profiles\claude-account-N`.
`CLAUDE_CONFIG_DIR` и `ANTHROPIC_CONFIG_DIR` задаются дочернему процессу; переменные API-ключей и альтернативной
авторизации в нём очищаются. Основной профиль Claude CLI остаётся отдельным.

Claude Code может потребовать платный тариф. Для Free вход и отображение процентов
лимитов не гарантируются. Если лимиты недоступны, плашка сообщает об этом.
Плашка автоматически запрашивает лимиты через команду `get_usage` в Claude Code.
Если версия CLI не возвращает лимиты, плашка читает сохранённые данные. Чтобы обновить
их вручную, выберите `Open Claude Code for this band`, выполните `/usage` и выйдите из
Claude. Проверка лимитов не расходует запросы к модели.

## Сборка

Windows 11, .NET 10 SDK, Command Palette с Dock и Codex CLI.
Используется CLI из локальной установки Codex desktop, затем из PATH.

```powershell
.\build.ps1
.\build-and-install.ps1
```

Установка перезапускает Command Palette. Пакет: VMGos.CodexUsageDock.
Профили вне AppData обходят виртуализацию MSIX и сохраняются при переустановке.
Оригинальная лицензия и THIRD_PARTY_NOTICES.md сохранены.
